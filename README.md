## Project Overview
A Power BI analytics project that transforms laundry service transaction data into actionable business insights. This interactive dashboard helps Love Laundry optimize operations, improve revenue, and enhance customer service.

## Key Features
- **Comprehensive KPI Tracking**: Total income, orders, machines used, and service types
- **Revenue Analysis**: Breakdown by service type and payment method
- **Customer Insights**: Identification of top-paying customers
- **Trend Visualization**: Monthly income patterns and payment status
- **Interactive Filters**: Dynamic slicing by service type and other dimensions

## Technical Details
- **Tools Used**: Power BI (Power Query, DAX)
- **Data Processing**: Cleansing, transformation, and creation of calculated measures
- **Visualizations**: KPI cards, bar charts, line graphs, column charts with slicers
- **Dataset**: 100 customer transactions across 5 services

## Key Findings
- Total income: ₦426K from 100 customers
- Top service: Dry Cleaning (₦114K revenue)
- Payment trends: 61% paid vs 39% unpaid orders
- Best month: October (₦152K income)

## How to Use
1. Download the `.pbix` file
2. Open in Power BI Desktop
3. Interact with slicers to filter views
4. Hover over visuals for detailed tooltips

## Installation
